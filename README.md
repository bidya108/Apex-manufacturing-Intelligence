# Apex Manufacturing Intelligence & Predictive Operations Platform

An end-to-end manufacturing data intelligence platform designed to support operational analytics, predictive maintenance, data quality management, machine learning, and business decision-making.

## Overview

Apex Manufacturing operates multiple production facilities with large volumes of production, machine, maintenance, quality, and sensor data.

This project demonstrates how manufacturing data can be transformed into actionable business intelligence through a complete data and analytics platform.

The solution covers:

- Business analysis and requirements
- Manufacturing data management
- PostgreSQL operational database
- Data validation and ETL pipelines
- Data warehouse
- SQL analytics
- Machine learning
- Predictive maintenance insights
- REST APIs
- JWT authentication
- Role-based access control
- Audit logging
- Interactive business dashboard
- Automated validation and testing

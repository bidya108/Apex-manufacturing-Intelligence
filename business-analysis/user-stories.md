# User Stories

## 1. Executive

### US-001
As an Executive, I want to view company-wide manufacturing KPIs, so that I can understand overall operational performance.

### US-002
As an Executive, I want to compare performance across facilities, so that I can identify areas requiring management attention.

### US-003
As an Executive, I want to receive alerts about major operational issues, so that I can take timely business decisions.


## 2. Production Manager

### US-004
As a Production Manager, I want to view production output by facility and production line, so that I can monitor production performance.

### US-005
As a Production Manager, I want to compare target production with actual production, so that I can identify production gaps.

### US-006
As a Production Manager, I want to analyze downtime and production efficiency, so that I can identify operational problems.

### US-007
As a Production Manager, I want to view production forecasts, so that I can plan future production activities.


## 3. Maintenance Manager

### US-008
As a Maintenance Manager, I want to view machine health and sensor information, so that I can identify machines requiring attention.

### US-009
As a Maintenance Manager, I want to view predicted machine failure risks, so that I can prioritize maintenance activities.

### US-010
As a Maintenance Manager, I want to view maintenance history for each machine, so that I can understand recurring maintenance problems.

### US-011
As a Maintenance Manager, I want to receive alerts for abnormal machine conditions, so that I can respond before serious failures occur.


## 4. Data Analyst

### US-012
As a Data Analyst, I want to access approved manufacturing datasets, so that I can perform business analysis.

### US-013
As a Data Analyst, I want to analyze manufacturing KPIs using SQL, so that I can identify trends and performance patterns.

### US-014
As a Data Analyst, I want to compare facilities, production lines, and machines, so that I can identify performance differences.

### US-015
As a Data Analyst, I want to create analytical reports, so that business teams can use data for decision-making.


## 5. Data Scientist

### US-016
As a Data Scientist, I want access to historical machine and production data, so that I can develop machine learning models.

### US-017
As a Data Scientist, I want to predict machine failures, so that maintenance teams can take preventive action.

### US-018
As a Data Scientist, I want to detect abnormal machine behavior, so that potential operational problems can be identified.

### US-019
As a Data Scientist, I want to forecast future production demand, so that operations teams can plan resources.


## 6. Data Administrator

### US-020
As a Data Administrator, I want to monitor data quality, so that unreliable data does not affect business analysis.

### US-021
As a Data Administrator, I want to identify missing, duplicate, and invalid records, so that data problems can be corrected.

### US-022
As a Data Administrator, I want to maintain metadata for important datasets, so that users understand the meaning and origin of data.

### US-023
As a Data Administrator, I want to monitor data pipeline status, so that failed or delayed data processing can be identified.


## 7. System Administrator

### US-024
As a System Administrator, I want to manage users and roles, so that users only access information appropriate to their responsibilities.

### US-025
As a System Administrator, I want to monitor authentication and system activity logs, so that security and operational issues can be investigated.

### US-026
As a System Administrator, I want to configure system permissions, so that access to the platform remains controlled.
